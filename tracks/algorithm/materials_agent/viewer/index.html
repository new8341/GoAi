使用方法（调试端）
  1. 顶部选择运行目录（推荐 production_sciverse），确认 badge 为 verify PASS。
  2. 总览：看验收检查项、全文解析覆盖、检索 Query。
  3. 文献：过滤 source / fulltext_source（Sciverse 应为 sciverse；解析可为 mineru 或 grobid_fusion）。
  4. Gaps：点左侧条目，核对 quote、provenance、下一步与证伪；与用户端对照同一 run。
  5. 需要黑盒叙事时点「用户界面」，用「打开已有运行」加载同一目录。
判断标准（白盒）

总览 / Verify

  • production_verification = PASS
  • 全文解析比例 ≥ 配置阈值（常见 ≥50%）
  • 无 local_cache 冒充生产证据
  • Gap 全文证据 spans > 0 且 quote 可回源

文献

  • Sciverse 轮次：多数 source=sciverse
  • audit 无 fallback openalex（除非预期降级）
  • 有 pdf_hash / 解析产物更可信

Gaps 与反向抽查

  • quote + paper_id + provenance 齐全
  • 类型与描述一致（尤其 contradiction）
  • 抽 2 条 quote 在全文中搜到原句才算通过

验收与一致性

通过标准：全部检查项为 pass；consistency PASS；解析来源为 mineru / grobid_fusion。

全文解析覆盖

通过标准：可解析占比达标；生产禁用 local_cache 作为证据。

    优化监控点

    目标：贴题≥70%、Gap对齐≥80%、噪声≤5%、溯源≥95%。未达标即下一轮优化方向。
