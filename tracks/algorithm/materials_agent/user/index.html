使用方法
  1. 新跑一轮：填写主题 → 选模式（推荐 Sciverse / 生产）→ 开始调研。
  2. 核验已有结果：下方选 production_sciverse → 打开（无需重跑）。
  3. 对照白盒：右上角「调试视图」看 verify / 解析源 / 证据 provenance。
  4. 正式抽检：按判断标准审 Gaps，结论写入 experiments/reviews/。
判断标准（用户端）

摘要条

  • 文献数尽量 ≥ 5
  • 研究空白 ≥ 1
  • 含全文尽量 ≥ 半数
  • 一致性显示「通过」更佳

每条 Gap（核心）

  • 标题像真缺口，非常识复述
  • 证据 quote 像论文原句，paper_id 可对上
  • 「下一步」可执行；「证伪」可设计实验/计算
  • 红旗：空证据、口号式 paraphrase、无法证伪

文献与报告

  • 标题贴题，多数有 DOI
  • 「全文可用」与摘要条大致一致
  • 报告中的 Gap 与面板不矛盾
