## 3. 使用的方法（技术与科学方法）

### 3.1 工程方法

1. **Profile 隔离**：smoke ≠ production，避免验收叙事偷换。  
2. **证据优先于生成**：先门禁再入库；生产 `allow_text_cache=false`。  
3. **合法 OA only**：不绕过付费墙；仓库镜像（Europe PMC / OSTI / arXiv）优先。  
4. **解析分轨**：生产默认 GROBID 主解析（Windows 避开 MinerU 挂死）；失败写 audit。  
5. **解析缓存**：`.pdf_hash` 命中则跳过重解析，降低重跑成本。  
6. **诚实降级**：LLM / MP / 下载失败均留痕，不伪造成功。  
7. **双界面验收**：黑盒测外部行为；白盒测内部 provenance。

### 3.2 科学发现方法（对齐赛题）

1. **AI-Ready 文献**：PDF → 结构化 Markdown/chunk，而非整文塞进上下文。  
2. **可证伪 Gap**：强制下一步实验 + falsification。  
3. **Known / New 分离**：密集区表抑制虚假新颖性。  
4. **生成–验证飞轮（轻量 GNoME 形）**：Route A 假说 → MP e_hull / is_stable 打脸。  
5. **评审分离**：gap_reviewer + 抽检轮次，降低自说自话。  
6. **引用即一等公民**：EvidenceSpan + quote-in-source。

### 3.3 对标的公开范式（方法出处）

| 方法思想 | 公开锚点 | 本仓库落点 |
|----------|----------|------------|
| 子任务可评测 | ScienceAgentBench | pipeline 分步 + verify 脚本 |
| 结论可追溯 | Kosmos / Claude Science | provenance + audit |
| 生成→过滤→验证 | DeepMind GNoME | Route A + MP |
| LLM 进进化环 | AlphaEvolve / co-scientist | SEED/SCORE/PRUNE |
| 环境工程 | EurekAgent 论述 | 配置、权限、依赖披露、人机抽检 |
