# 免费 / 可申请免费访问的权威论文库指南

> 用途：训练与扩充本仓库 **Materials Agent** 的检索、全文、证据链能力。  
> 原则：**只用法理上的开放获取（OA）或机构合法授权**；不买「爬墙全文包」，不绕过付费墙。  
> 相关：[`文献库获取与缺口.md`](文献库获取与缺口.md) · **一览表（链接/特色/领域/事件）**：[`免费论文库一览表.md`](免费论文库一览表.md) · 本仓库已接 OpenAlex / Unpaywall / Sciverse / Europe PMC / OSTI / arXiv 链路。

---

## 0. 怎么选（给 Agent 训练用）

| 你想做的事 | 优先用 |
|------------|--------|
| 大规模元数据检索、主题过滤 | **OpenAlex**、Crossref、Semantic Scholar |
| 已知 DOI → 找合法免费 PDF | **Unpaywall**、Open Access Button |
| 生物医学 / 生命科学全文 | **Europe PMC**、PubMed Central |
| 预印本（物理/材料/化学常见） | **arXiv**、chemRxiv、bioRxiv |
| 机构知识库聚合全文 | **CORE**、BASE、OpenAIRE Explore |
| 材料计算数据（非论文，但可外验） | **Materials Project**、OQMD、NOMAD |
| 赛题推荐语义检索 | **Sciverse** |
| 离线大批量「喂」Agent | OpenAlex / Unpaywall **数据快照**，勿高频狂打在线 API |

下面每个库按同一模板写：**是什么 → 费用 → 注册 → 怎么用 → 对本 Agent 的价值**。

## 1. OpenAlex（全球学术图谱 · 首选元数据）

| 项 | 说明 |
|----|------|
| 官网 | https://openalex.org |
| 开发者文档 | https://developers.openalex.org |
| 权威性 | OurResearch 维护；覆盖数亿 works，常作 Web of Science/Scopus 的开放替代 |
| 费用 | **数据本身免费**；API 为 freemium（免费日额度 + 超量付费） |

### 注册 / 拿 Key

1. 打开 https://openalex.org ，注册账号（邮箱即可）。  
2. 登录后进入 https://openalex.org/settings/api ，复制 **API Key**（免费）。  
3. 无 Key 时额度极低，仅适合试玩；生产请务必用 Key（每日约有免费额度，详见官方 Pricing）。

### 使用方法

```text
# 带 Key 的检索示例
https://api.openalex.org/works?search=SnSe%20thermal%20conductivity&filter=is_oa:true&api_key=YOUR_KEY
```

本仓库：

```env
OPENALEX_EMAIL=你的邮箱@example.com
OPENALEX_API_KEY=你的免费Key   # https://openalex.org/settings/api
```

配置：`configs/default.yaml` / `production.yaml` 等已映射 `retrieval.openalex_api_key: ${OPENALEX_API_KEY:}`。请求会自动带 `api_key=`（有 Key 时）与 `mailto=`。

### 对本 Agent

- **已接入**：主检索源。  
- 训练建议：用 `filter=is_oa:true` 缩小可下载全文集合；大批量训练优先下 **OpenAlex Snapshot**，别靠刷 API。

## 2. Unpaywall（DOI → 合法 OA 链接）

| 项 | 说明 |
|----|------|
| 官网 / API | https://unpaywall.org/products/api |
| 权威性 | OurResearch；基于 DOI 聚合出版商与仓储的合法免费版 |
| 费用 | **免费**（非商用常见限额约 10 万次/天；超量下快照） |

### 注册

**不需要注册账号**。每次请求带真实联系邮箱即可。

### 使用方法

```text
https://api.unpaywall.org/v2/10.1038/nature12373?email=你的邮箱@example.com
```

本仓库 `.env`：

```env
UNPAYWALL_EMAIL=你的邮箱@example.com
```

### 对本 Agent

- **已接入**：生产链路找 OA PDF。  
- 训练建议：先有 DOI 列表（来自 OpenAlex），再批量问 Unpaywall，只保留 `is_oa=true` 且有 `url_for_pdf` 的条目。

## 3. Crossref（DOI 元数据权威源）

| 项 | 说明 |
|----|------|
| 官网 | https://www.crossref.org |
| REST API | https://www.crossref.org/documentation/retrieve-metadata/rest-api/ |
| 权威性 | DOI 注册机构联盟；元数据行业标准 |
| 费用 | **免费公开 API**（礼貌池） |

### 注册

可不注册。强烈建议在请求里加 `mailto=你的邮箱`，进入更高速率的 polite pool。

可选：https://www.crossref.org/ 注册会员账号（个人研究者通常不必）。

### 使用方法

```text
https://api.crossref.org/works?query.bibliographic=SnSe%20vacancy&mailto=你的邮箱@example.com
https://api.crossref.org/works/10.1038/nature12373
```

### 对本 Agent

- 未作为主检索默认源，但适合：**DOI 校验、补全题名/年份/出版社、引用关系**。  
- 训练建议：用 Crossref 清洗金标准里的 DOI，再交给 Unpaywall。

## 4. Semantic Scholar（语义检索 + 图谱）

| 项 | 说明 |
|----|------|
| 官网 | https://www.semanticscholar.org |
| API 说明 | https://www.semanticscholar.org/product/api （或 api.semanticscholar.org） |
| 权威性 | Allen Institute for AI；学术搜索与推荐常用 |
| 费用 | **免费**；无 Key 有共享限流，有 Key 更稳 |

### 注册 / 申请 Key

1. 打开 Semantic Scholar API 产品页，找到 **Request an API Key**。  
2. 填写用途（写明 academic / open-source agent / non-commercial）。  
3. 邮件收取私有 Key（勿提交 Git）。

### 使用方法

```text
# 示例：按关键词搜论文（具体路径以官方最新文档为准）
GET https://api.semanticscholar.org/graph/v1/paper/search?query=SnSe+thermal+conductivity
Header: x-api-key: YOUR_KEY
```

另有 **Academic Graph Dataset** 可批量下载，适合离线训练。

### 对本 Agent

- ✅ **已接入**：`retrieval.backend: semantic_scholar`（别名 `s2`）。  
- 配置：`configs/production_semantic_scholar.yaml`；环境变量 `S2_API_KEY`。  
- 失败（无结果 / 429）自动回退 OpenAlex，并写入 `audit.json`。  
- 训练建议：同主题下对比 OpenAlex vs Semantic Scholar 召回，写进 `experiments/`。

## 5. CORE（开放仓储全文聚合）

| 项 | 说明 |
|----|------|
| 官网 | https://core.ac.uk |
| API 文档 | https://core.ac.uk/documentation/api |
| 权威性 | 开放获取仓储聚合器（多机构库） |
| 费用 | **免费层 + 注册 Key**（更高配额） |

### 注册

1. 打开 https://core.ac.uk/services/api （或文档中的注册入口）。  
2. 注册研究者/开发者账号，创建 API Key。  
3. 遵守使用条款：仅用于合法 OA，注意再分发限制。

### 使用方法

按官方文档用 Key 调用 search / get full text 等端点（路径以当前文档为准）。

### 对本 Agent

- 适合补：**机构库绿 OA**（出版社页没有、仓储里有）。  
- 训练建议：对 Unpaywall 未找到 PDF 的 DOI，再问 CORE 一轮。

## 6. Europe PMC / PubMed Central（生物医学全文重镇）

| 项 | 说明 |
|----|------|
| Europe PMC | https://europepmc.org |
| REST | https://europepmc.org/RestfulWebService |
| PubMed / NCBI | https://www.ncbi.nlm.nih.gov/home/develop/api/ |
| 权威性 | EMBL-EBI / NIH；生命科学金标准之一 |
| 费用 | **免费** |

### 注册

- Europe PMC REST：**一般无需 Key**。  
- NCBI E-utilities：建议申请 **API Key**（https://www.ncbi.nlm.nih.gov/account/ ），提高限流；请求加 `api_key=` 与邮箱。

### 使用方法

```text
# Europe PMC 检索示例
https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=SnSe%20thermoelectric&format=json
```

本仓库 OA 解析会把部分 PMC 链接规范到 Europe PMC PDF。

### 对本 Agent

- **已部分接入**（OA PDF 规范化）。  
- 材料题也可碰到交叉领域（能源、生物矿化等）；纯材料仍以 arXiv / 出版商 OA 为主。

## 15. 可「申请免费访问」的机构路径（不是买库）

| 路径 | 谁能用 | 怎么申请 | 注意 |
|------|--------|----------|------|
| **高校 / 研究所图书馆** | 在校师生、职工 | 图书馆开户 → VPN / 统一认证 / 校外访问 | 仅个人合法阅读；**禁止**批量爬取付费 PDF 进公开仓库 |
| **Research4Life** | 符合条件的发展中国家机构 | https://www.research4life.org 机构申请 | 机构资格，不是个人随意买账号 |
| **作者主页 / 绿 OA** | 所有人 | Unpaywall、作者 ResearchGate 合法分享、机构库 | 只下许可允许的版本 |
| **出版社「免费试读 / OA 专刊」** | 所有人 | 各社官网 OA 筛选 | 勿用破解扩展 |

对本 Agent：校内下的授权 PDF 可放本地 cache 做**私有训练**，但生产默认路径与开源披露仍应走 OA。

## 17. 不建议当「免费训练源」的

| 类型 | 原因 |
|------|------|

## 18. 推荐组合拳（训练本 Agent）

### A. 最小免费闭环（已与仓库对齐）

1. OpenAlex（注册 Key + 邮箱）检索 OA 文献  
2. Unpaywall（邮箱）解析合法 PDF 链接  
3. 下载 PDF → MinerU / GROBID 解析  
4. 写入 `data/<主题>_<时间>/` 做语料  
5. Materials Project Key 做路线 A 外验  

### B. 增强召回（建议逐步加）

1. Semantic Scholar Key → 第二路检索  
2. CORE Key → 补绿 OA  
3. Europe PMC → 交叉领域全文  
4. arXiv API → 预印本专轨  
5. Sciverse Token → 对齐赛题推荐链  

### C. 离线大规模训练

1. 下载 OpenAlex Snapshot / Unpaywall Data Feed（按官方许可）  
2. 本地过滤材料主题 + `is_oa`  
3. 再解析全文，避免打爆在线 API 日额度
