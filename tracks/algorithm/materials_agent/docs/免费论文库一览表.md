## 最小可跑清单（本仓库）

在 `tracks/algorithm/materials_agent/.env` 至少准备：

```env
OPENALEX_EMAIL=你的邮箱
OPENALEX_API_KEY=你的OpenAlex免费Key
UNPAYWALL_EMAIL=你的邮箱
# 可选但推荐
SCIVERSE_API_TOKEN=
MP_API_KEY=
```

然后：

```bash
cd tracks/algorithm/materials_agent
python scripts/run_survey.py survey -c configs/production.yaml
python scripts/verify_production.py -c configs/production.yaml
# 有 Sciverse Token 时改用 configs/production_sciverse.yaml
# 有 MP Key 时再跑 scripts/run_route_a.py
```

## 按「训练 Materials Agent」怎么挑（短表）

| 目标 | 优先库 | 项目侧动作 |
|------|--------|------------|
| 搜文献元数据 | OpenAlex → Sciverse → Semantic Scholar | 填邮箱 / Sciverse Token / `S2_API_KEY`；跑对应 yaml |
| 下合法 PDF | Unpaywall → arXiv / Europe PMC / OSTI | 填 `UNPAYWALL_EMAIL`；生产配置 |
| 材料预印本 | arXiv（经 OA 链） | 生产链即可；专搜可后扩 |
| 构效外验 | Materials Project → OQMD | `MP_API_KEY` + `run_route_a.py` |
| 对齐赛题 | Sciverse + 上述 OA 链 | `production_sciverse.yaml` |
