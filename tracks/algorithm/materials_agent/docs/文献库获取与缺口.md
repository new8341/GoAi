## 1. 哪里可以「买 / 申请」论文库？

| 路径 | 费用 | 能否用于本 Agent | 怎么拿到 |
|------|------|------------------|----------|
| **OpenAlex**（当前默认） | 免费（API 有日额度） | ✅ 元数据检索 | 填 `OPENALEX_EMAIL` + 建议填 `OPENALEX_API_KEY`（https://openalex.org/settings/api） |
| **Unpaywall / arXiv / OSTI / Europe PMC** | 免费 | ✅ OA 全文 | 已接；填 `UNPAYWALL_EMAIL` |
| **Sciverse（穹宇）** | 平台额度（竞赛推荐） | ✅ 元数据 + 语义检索（有 Token） | 见下方步骤 |
| **Sci-Base（HF）** | 免费（CC-BY-4.0 结构） | ✅ 材料子集缓存 / hybrid 检索 | https://huggingface.co/datasets/opendatalab/Sci-Base ；`scripts/build_scibase_cache.py` → `backend: sciverse_scibase` |
| **Semantic Scholar** | 免费（有 Key 更稳） | ✅ 第二检索后端 | `.env` 填 `S2_API_KEY`；`-c configs/production_semantic_scholar.yaml` |
| **高校图书馆订阅**（Elsevier / Springer / Wiley…） | 学校已付 | ⚠️ 仅合法个人/机构访问；**禁止**把付费 PDF 批量爬进公开仓库 | 用学校 VPN / 图书馆代理手动下载后放入本地 cache（非默认生产路径） |
| **商业全文 API / 数据包** | 通常很贵 | ❌ 竞赛不要求；合规与版权风险高 | 不推荐为冲分路径 |

### 1.1 Sciverse 申请步骤（需你操作）

1. 打开 [https://sciverse.space](https://sciverse.space)，注册 / 登录控制台（platform-console）。
2. 在控制台创建 **Bearer Token**（文档称 `SCIVERSE_API_TOKEN`）。
3. 把 Token 写入本仓库 `tracks/algorithm/materials_agent/.env`（**不要提交 git**）：

```env
SCIVERSE_API_TOKEN=你的token
# 兼容旧名亦可：
# SCIVERSE_API_KEY=你的token
SCIVERSE_BASE_URL=https://api.sciverse.space
```

4. 检索后端改为 Sciverse（任选其一）：

```yaml
# configs 里
retrieval:
  backend: sciverse
  sciverse_mode: meta   # meta | semantic | hybrid
  sciverse_api_token: "${SCIVERSE_API_TOKEN:}"
  sciverse_base_url: "${SCIVERSE_BASE_URL:https://api.sciverse.space}"
```

或直接用已准备的配置：

```bash
cd tracks/algorithm/materials_agent
python scripts/run_survey.py survey -c configs/production_sciverse.yaml
```

5. 授权我之后：把 Token 放进 `.env` 并说一声「已写入」，我即可帮你跑通一轮并核对 `audit.json` 里 `tool=sciverse`。

官方 SDK（可选）：`pip install sciverse`；本仓库已用 **HTTP 直连** `/meta-search`、`/agentic-search`，不强制装 SDK。

### 1.2 不要「买库」的原因（一句话）

赛题加分点是 **可复现的 OA + 证据链**，不是付费全文覆盖率；买库既贵又难开源披露，还容易踩版权。

## 2. 与「缺 Sciverse」同类的缺口

| 缺口 | 状态 | 谁来做 | 具体步骤 |
|------|------|--------|----------|
| Sciverse Token + 真检索 | 代码已接；等 Token | **你申请 Token** → 我跑验证 | 见 §1.1 |
| OpenAI / 兼容 LLM 额度 | Cursor Win 桥不稳；OpenAI 曾额度耗尽 | **你充值或换可用 Key** | `.env` 设 `OPENAI_API_KEY`（有余额），再跑 `scripts/run_route_a.py`，目标 `role_trace` 出现 `llm_*` |
| ≥3 条 Gap 人工抽检 | 模板已有 | **你或队友填写** | 见 `experiments/reviews/README.md`，写入 JSON 评审 |
| 金标准 coverage 偏低（demo≈0.3） | 评测骨架有 | **一起扩 gold / 收紧主题** | 扩 `experiments/gold/` 或换更窄 topic 后再 `eval` |
| 更多合法 OA PDF | 生产已 7/10 | 可选 | 仅 Unpaywall/机构合法链路；勿 ScienceDirect `/abs/` 硬爬 |
| Materials Project 额度 | 已通真 API | 额度不够时找我 | 换/续 `MP_API_KEY` |
| Qdrant / GROBID / MinerU 本机服务 | Docker 文档已有 | 环境挂了时找我 | `docker compose` + `MINERU_MODEL_SOURCE=local` |
