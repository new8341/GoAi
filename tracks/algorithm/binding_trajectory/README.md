# 方向二：小分子–蛋白质结合轨迹预测

在 MISATO 数据集上学习结合动力学，预测未见复合物的结合轨迹；主榜侧重单轨迹重建。

## 目录约定

```
binding_trajectory/
├── data/           # MISATO 划分与本地缓存（大文件勿入库，用 .gitignore）
├── src/            # 轨迹模型、物理约束、rollout
├── baselines/      # NeuralMD / 静态不动 / 线性外推等
├── configs/
├── experiments/
├── scripts/
└── README.md
```

## 评测场景（加权）

| 场景 | 设定 | 权重（最终主榜） |
|------|------|------------------|
| T1 | 短程：predict next k frames | 50% |
| T2 | 长观测：前 80% 训、后 20% 测 | 30% |
| T3 | 少观测：前 20% 训、后 80% 测 | 20% |

单场景分：`Score = 40% Geo + 25% Phys + 25% Dyn + 10% Stab`（相对基线归一化）。

## 防泄漏

按蛋白序列一致性与配体骨架/相似度切分；外部预训练/MD 数据不得含测试集或其近同源体系。

## 主榜提交

- 预测轨迹文件（官方模板：体系 ID 与帧规范不可改）。
- 复现包与外部资源披露。
- 决赛应用题：指定靶点–配体上的下游任务设计报告。
