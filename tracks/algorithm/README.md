# 算法赛题 · tracks/algorithm

在给定数据集与评测框架内提交解法。报名时**选定一个方向**，统一评分、统一排名。

## 方向

| 目录 | 方向 | 核心任务 |
|------|------|----------|
| [`virtual_cell/`](virtual_cell/) | 虚拟细胞 | 酿酒酵母扰动蛋白质组响应预测（封闭数据榜 / 开放知识榜） |

## 统一评审权重（跨方向）

- 技术性能 45%（方向内归一化成绩）
- 科学意义 30%
- 方法创新性 20%
- 开源贡献 5%

各方向内量化指标见官方手册第二节；提交材料放入对应方向目录，定稿再同步到 `submissions/`。
