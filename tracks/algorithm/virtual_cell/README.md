# 方向一：虚拟细胞（虚拟酵母扰动响应预测）

基于酿酒酵母扰动蛋白质组数据，预测未见化合物、未见菌株及二者组合下的完整蛋白质组响应。

## 目录约定

```
virtual_cell/
├── data/           # 官方 train_val / test（勿提交敏感数据到公开仓库）
├── src/            # 模型、特征、训练与推理
├── baselines/      # 均值 / RF / GBDT 等对照
├── configs/        # 训练与评测配置、随机种子
├── experiments/    # 实验记录与指标
├── scripts/        # 训练、预测、打包脚本
└── README.md
```

## 评测场景

| 场景 | 划分 | 考察点 |
|------|------|--------|
| S1 | 已见菌株 + 未见化合物 | 新扰动外推 |
| S2 | 未见菌株 + 已见化合物 | 新遗传背景外推 |
| S3 | 未见菌株 + 未见化合物 | 双重未知泛化 |
