# 开放探索赛题 · tracks/open_exploration

自定义真实科学问题，构建 Agent 可进入、尝试、修正并持续探索的环境。无标准答案；**被清晰解释的负结果同样有价值**。

## 三条核心约束

1. **真实问题**：尚无公认答案或未充分结构化，须有文献/数据/专家依据。  
2. **探索环境**：Agent 在哪行动、看到什么、能改变什么、如何获得反馈；固定 vs 可探索部分要写清。  
3. **发现信号**：探索开始前定义何为发现（正结果 / 异常 / 反例 / 稳定负结果 / 问题修正）。

## 目录约定

```
open_exploration/
├── problem_definition/   # 初赛 ≤4 页问题定义文档草稿与定稿
├── environment/          # 探索环境实现（固定规则 / 动作 / 反馈）
├── discovery_signals/    # 发现信号定义与检测逻辑
├── baselines/            # 随机探索、平凡解、空模型等最小参照系
├── logs/                 # 至少一次完整运行日志（复赛必交）
├── src/                  # Agent 与编排代码
├── configs/
├── scripts/
└── README.md
```

## 评审权重

- 问题定义与环境设计质量 45%  
- 探索过程与科学/研究信号 35%  
- 可检查性与可延续性 20%  

## 提交节奏

| 阶段 | 材料 |
|------|------|
| 初赛 | `problem_definition/` 定稿（≤4 页） |
| 复赛 | 可运行环境 + `logs/` + 参照系 + 复现说明 |
| 决赛 | 探索报告 + 答辩材料 + 最终仓库 |

## 自检（提交前）

- 去掉 AI，问题本身是否仍成立？  
- 去掉领域名，是否仍是研究问题而非纯工程任务？  
- Agent 行动是否改变后续观察与决策？  
- 是否有最小参照系排除「随机运气」？  
- 失败结果能否改进下一版问题定义？
