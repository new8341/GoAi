# 各方向探索报告（选型决策用）

> 用途：横向对比「涉及知识 / 前沿创新 / 出圈机会 / 最小必要知识 / 成才路径 / 前沿方法 / 比赛可用思路」。  
> 两类赛题独立评审；算法赛三个方向**统一排名**，方向只是切入口。

## 总览对比

| 维度 | 方向一 虚拟细胞 | 方向二 结合轨迹 | 方向三 材料 Agent | 开放探索 |
|------|----------------|----------------|-------------------|----------|
| 问题形态 | 表格型外推预测 | 物理轨迹生成/重建 | 文献→可证伪发现 | 自建环境+发现信号 |
| 主能力栈 | 表格 ML + 生物先验 | 几何深度学习 + MD | LLM Agent + 材料知识 | 环境工程 + 领域切片 |
| 算力敏感度 | 中 | **高** | 中（API 费用敏感） | 视环境而定 |
| 数据门槛 | 官方非公开数据 | MISATO 公开但体积大 | Sci-Base / Sciverse 等 | 自备或仿真 |
| 评审抓手 | 量化主榜 45% 权重入口 | 同左 + 物理合法性 | 基本任务 50% + 路线 50% | 问题/环境设计 45% |

| **相对出圈难度** | 中高（榜强卷） | 高（基线 NeuralMD 强） | **中（工程+证据链可拉开）** | **中低（设计质量决定上限）** |

## 方向一：虚拟细胞（虚拟酵母扰动蛋白质组预测）

**任务一句话**：用有限扰动蛋白质组，泛化到未见化合物 / 未见菌株 / 二者组合，预测完整 log2 蛋白丰度向量；评分强调扰动效应（FC）而非只拟合绝对值。

### 探索报告表

| 栏目 | 内容 |
|------|------|
| **涉及知识** | 蛋白质组学与质谱批次效应；酿酒酵母遗传/化学扰动；条件编码（菌株、化合物、培养基、温度、时间）；表格深度学习（MLP / Transformer / TabPFN 类）；表示学习与实体嵌入；因果/反事实式扰动效应建模；跨条件域泛化（OOD）；基因组尺度代谢模型（GEM）作先验；通路与 PPI 网络 |
| **前沿研究报告给出的创新** | **ProteinTalks**（2025，扰动蛋白质组 + Neural ODE）把蛋白网络动力学当基础模型预训练目标；**X-Cell** 等虚拟细胞大模型走规模化 Perturb-seq 零样本外推；多组学扰动对齐（如 adversarial alignment）；「拟合表达 → 建模调控/机理」的范式转移；Virtual Cell Challenge 推动标准化评测闭环 |
| **可脱颖而出的机会方向** | ① 封闭榜：把官方评分模块（对照匹配 FC、上下文/药物均值残差）**直接写进损失函数与验证集设计**，而非只刷整体 PCC；② 显式建模测量上下文（仪器/板号）吸收批次，同时保证菌株/化合物实体泛化；③ 开放知识榜：用酵母 GEM / STRING / 文献知识做可复现的软约束或检索增强，且**完整审计外部调用**；④ 高效应蛋白 / DEP 检出作为可解释加分与科学叙事；⑤ 机理事后分析（不作主榜）做成决赛展示差异化 |
| **最小必要知识** | Python + PyTorch；pandas 处理宽表；交叉验证与泄漏防范；PCC / R² / Δ=treat−control；embedding 与多任务回归；读懂官方字段字典与 S1/S2/S3 划分；基本酵母/药物扰动概念 |
| **成为专家的路径** | Week1：跑通官方基线（均值/RF/GBDT）复现模块分数 → Week2–3：实体嵌入 + 条件交互模型，按评分权重调验证 → Week4：残差/对照匹配训练目标对齐主榜 → Week5：开放知识榜工具链与消融 → 持续读扰动蛋白质组与虚拟细胞综述，用 SHAP/通路富集讲清科学意义 |
| **领域内最前沿研究方法** | 扰动基础模型（Neural ODE / 扩散 / 大规模 Transformer）；图神经网络 + 基因调控先验；因果表示与不变风险最小化（IRM）；跨细胞系/跨物种迁移；多组学联合扰动预测；可解释机理探针（靶点一致性） |
| **可为比赛提供思路的知识** | ① scPerturb / GEARS / scGPT 等**转录组扰动**方法迁移到蛋白质组（注意模态差异）；② 药物–细胞协同嵌入（类似 DeepDDS / chemBERTa 分子表征）；③ 批次校正（Harmony/ComBat 思想）但只用于训练侧；④ 对照匹配与差分数应损失；⑤ 代谢网络通量约束作正则；⑥ 集合模型与校准（温度缩放）提升 R² |

### 关键文献 / 锚点

| 类型 | 锚点 |
|------|------|
| 赛题基线 | 官方均值 / RF / GBDT；GEM 参考基线 |
| 前沿 | ProteinTalks（bioRxiv 2025）；AI-driven virtual cell 综述（npj Digital Medicine 2025）；Cell Genomics 扰动蛋白质组专论 |
| 可借鉴方法族 | GEARS、scGPT、Geneformer、化学信息学分子指纹/图编码 |

## 方向二：小分子–蛋白质结合轨迹预测（MISATO）

**任务一句话**：在 MISATO 上学习结合动力学，对未见复合物预测轨迹；主榜 Score = 40% Geo + 25% Phys + 25% Dyn + 10% Stab，场景 T1/T2/T3 加权。

### 探索报告表

| 栏目 | 内容 |
|------|------|
| **涉及知识** | 分子动力学（牛顿力学、力场、积分器）；蛋白–配体相互作用与口袋；SE(3)/E(3) 等变图网络；Neural ODE/SDE；轨迹 rollout 稳定性；几何指标（RMSD、RMSF、接触/氢键）；物理合法性（键长键角、碰撞、能量）；防泄漏切分（序列一致性、配体骨架相似度） |
| **前沿研究报告给出的创新** | **NeuralMD**（Nature Communications 2025）：BindingNet 多粒度群对称 + 增广神经微分方程，在 MISATO 上显著降重建误差、提合法性，相对数值 MD 可加速数量级；**BioMD** 等生成式全原子动力学，强调构象柔性与解绑路径；半柔性设定（蛋白固定）降低算力门槛；从「静态对接」转向「动力学代理模型」 |
| **可脱颖而出的机会方向** | ① 不只压低 RMSD：联合优化 Phys/Dyn，避免平滑塌缩刷分；② T3 少观测长时程：**稳定性正则 / 多步训练 / 噪声注入**专门打 Stab；③ 显式接触与氢键分布匹配（JS/Wasserstein）对准 Dyn；④ 轻量 equivariant 骨干 + 蒸馏/分阶段训练，在有限算力下逼近 NeuralMD；⑤ 决赛下游题（结合稳定性排序、口袋柔性代理量）提前做成可展示流水线；⑥ 平凡基线（静态/线性）对照写进报告，证明学到动力学 |
| **最小必要知识** | 基础 MD 概念；PyTorch Geometric 或同类；坐标/原子类型张量处理；RMSD 与简单合法性检查；读 NeuralMD 仓库与 MISATO 数据格式；训练短程再扩展 rollout |
| **成为专家的路径** | Week1：复现 NeuralMD semi-flexible 实验与指标脚本 → Week2：实现 Static / Verlet / GNN 对照 → Week3：改 BindingNet 或损失（物理项、分布项）→ Week4：T2/T3 专用训练课表与漂移抑制 → Week5：泛化切分审计 + 下游应用原型；同步补力场与统计力学直觉 |
| **领域内最前沿研究方法** | 物理信息 Neural ODE/SDE；多粒度（原子–残基–配体）对称网络；机器学习力场（MACE、NequIP、ANI）；生成式轨迹 / 流匹配 / 扩散 MD；长时程增强采样与集体变量；代理模型 + 偶发数值 MD 校正 |
| **可为比赛提供思路的知识** | ① NeuralMD 的对称帧与牛顿约束直接对标官方 Phys；② Denoising Score / 扩散用于构象分布（Dyn）；③ 机器学习势函数作能量合法性惩罚；④ curriculum：先 T1 再加长 rollout；⑤ 配体–口袋相对坐标与局部帧降低绝对坐标漂移；⑥ 多轨迹子任务若开放，用分布距离而非单轨迹 RMSE |

### 关键文献 / 锚点

| 类型 | 锚点 |
|------|------|
| 数据 | MISATO（Nat Comput Sci 2024） |
| 官方主基线 | NeuralMD（Nat Commun 2025），仓库 `chao1224/neuralmd` |
| 对照 | Static、线性外推、GNNMD、DenoisingLD、BioMD |

## 方向三：材料科学文献驱动的科学发现智能体

**任务一句话**：必做文献调研 Agent（检索–抽取–Gap–结构化报告+证据链），再选路线 A 构效 / B 模拟创新 / C 合成工艺之一深入；方向内 50%+50%。

### 探索报告表

| 栏目 | 内容 |
|------|------|
| **涉及知识** | 材料学构效关系（组分–结构–工艺–性能）；科学文献 RAG / Agent；PDF 解析（MinerU）；知识图谱与结构化抽取；Research Gap 表述与可证伪假设；工具调用与可审计证据链（Sciverse MCP）；路线 A：贝叶斯优化 / MCTS / 遗传算法 / 符号回归 **与 LLM 深度耦合**；路线 B：DFT/MD 代理、MACE/NequIP/CHGNet；路线 C：逆向合成与工艺约束 |
| **前沿研究报告给出的创新** | **AlphaAgent** 类：用 skill contract 拆开检索与报告，强调证据对齐与可信边界；**ComProScanner**：多 Agent 从全文抽 composition–property 结构化库；**MKNA**：自然语言 → 数据库/代理模型/稳定性验证闭环；**SciAgents / dZiner / Dolphin**：知识图谱 + 工具 + 实验反馈的假设生成；材料 Agent 从「问答」升级为「可验证发现」 |
| **可脱颖而出的机会方向** | ① 基本任务做到极致：每条 Gap **可追溯引用 + 矛盾结论表 + 可操作下一步实验/计算**（评委最易打分）；② Sciverse MCP 调用日志当天然证据链，开源可复现流水线；③ 路线 A：LLM 不只写代码，而参与**假设播种、中间科学合理性评判、搜索剪枝**（手册明确考察点）；④ 与 Materials Project / OQMD / NOMAD **交叉验证**当加分；⑤ 选窄而深的细分（如某类热电/催化）展示领域理解，避免空泛「新材料」；⑥ 路线 B 若有算力：在公认 benchmark 上报效率–精度 Pareto，故事清晰 |
| **最小必要知识** | LLM Agent 框架（工具调用、记忆、评估器）；RAG 与引用规范；材料论文读法（Abstract–方法–图表）；JSON Schema 抽取；一条进阶路线的最小算法（例如 BO 或简单 GA）；会写结构化 Markdown/报告 |
| **成为专家的路径** | Week1：打通 MinerU + Sciverse/本地库 → 固定 schema 抽取 → Week2：Gap 检测器（矛盾、缺失连接、未探索条件空间）与报告模板 → Week3：选定 A/B/C，做最小闭环（10 次搜索或 1 个 benchmark）→ Week4：证据链可视化与对照「已知 vs 新知」→ Week5：消融（无工具 / 无搜索 / 无数据库验证）证明 Agent 贡献 |
| **领域内最前沿研究方法** | Skill/契约化多 Agent；证据感知生成；文献→结构化数据库自动构建；LLM + 黑盒优化联合搜索；ML 势函数与生成模型加速模拟；自驱动实验室 / 闭环实验规划；材料知识导航与假设自动验证 |
| **可为比赛提供思路的知识** | ① 树搜索 + LLM 评价器（类 AlphaEvolve / MCTS-RAG）；② 符号回归发现可解释 SPR；③ 知识图谱多跳推理找隐藏连接；④ 引用图与共被引发现空白；⑤ 工具失败与拒答策略（提高可信度分数）；⑥ 路线 C：约束满足 + 文献先例检索，禁止「无依据合成步骤」 |

### 路线速选

| 路线 | 更适合谁 | 比赛叙事关键词 |
|------|----------|----------------|
| A 构效关系 | 有优化/搜索背景 + 能讲清材料机理 | LLM–搜索融合、可解释 SPR、数据库验证 |
| B 模拟创新 | 有 DFT/MD/MLFF 经验与算力 | benchmark 增益、精度–效率权衡 |
| C 合成工艺 | 化学/化工背景，重可验证性 | 逆向合成、条件优化、文献/计算验证 |

## 开放探索赛题

**任务一句话**：自选真实未解问题 → 定义 Agent 探索环境（固定/可探索/反馈）→ 预先定义发现信号与最小参照系；负结果可得分。

### 探索报告表

| 栏目 | 内容 |
|------|------|
| **涉及知识** | 问题切片与研究设计；Agent 环境工程（动作、观测、奖励/反馈、权限）；日志与可检查性；参照系（随机、平凡、无干预）；领域仿真或真实数据协议；科学哲学层面的「发现」操作化；可选 RL / 进化搜索 / 工具调用 Agent |
| **前沿研究报告给出的创新** | **EurekAgent**：主张瓶颈在 **environment engineering**（权限、产物、预算、人机回路）而非堆工作流；**The Station**：开放世界多 Agent 科研生态与涌现叙事；**SCION**：科研操作系统 + Research Execution Plan，可审计可复用；从「自动写论文」转向「可评审的探索环境」——与赛题三条约束高度同构 |
| **可脱颖而出的机会方向** | ① 问题切在「比赛周期内可跑、领域专家看得懂」的窗口（手册样例：微通道热流固、喷注不稳定窗口、托卡马克运行窗口、量子光路、订单簿冲击恢复等）；② 环境工程做到位：固定规则、动作空间、反馈、失败模式全部文档化；③ **预先**定义正/负/异常信号 + 平凡参照，避免事后叙事；④ 完整运行日志与可复现种子，对准「可检查性与可延续性 20%」；⑤ 冲击「范式创造奖」：若做出可迁移的动态评测/环境骨架，需有具体领域实例跑通；⑥ 明确不做：宏大标题、纯 LLM 角色扮演、无参照系的收益优化 |
| **最小必要知识** | 能写清 4 页问题定义；实现最小环境（Python 模拟器或 API 封装）；Agent 循环（propose–act–observe–log）；至少一种参照策略；领域最小文献综述证明「真未解」 |
| **成为专家的路径** | Day1–3：用手册自检清单砍掉弱问题 → Week1：冻结问题定义文档 → Week2：环境骨架 + 随机 Agent 跑通日志 → Week3：改进探索策略并记录负结果 → Week4：对照参照系写探索报告；全程保持「评委可复现」优先于「刷好看指标」 |
| **领域内最前沿研究方法** | Agent 环境工程；开放世界科研模拟；自进化 / 自我改进 Agent；可审计工具链与预算感知探索；人机协同发现；领域专用世界模型 + 规划 |
| **可为比赛提供思路的知识** | ① 把赛题样例的「固定/可探索/反馈/发现信号」当成模板填空；② Gym/PettingZoo 式 API 让环境可插拔；③ 进化算法或 bandit 作参照探索器；④ 实验设计（DOE）思想定义动作空间；⑤ 失败案例库作为一等公民产出；⑥ 动态 benchmark（题目随 Agent 能力变）需先有领域实例 |

### 强项目 vs 弱项目（手册提炼）

| 强项目特征 | 弱项目特征 |
|------------|------------|
| 真实未解 + 切片适中 | 终极问题口号 |
| 环境清楚、反馈可迭代 | 只有最终分数 |
| 发现信号预先定义 | 事后成功标准 |
| 有随机/平凡参照 | 无法排除运气 |
| 日志可检查、可延续 | 漂亮截图无法复查 |

## 选型建议（务实）

| 若你的团队更像… | 更建议 | 理由 |
|-----------------|--------|------|
| 强表格 ML / 生物信息，算力中等 | 方向一 | 指标清晰，工程迭代快；出圈靠「评分对齐 + 残差/对照」 |
| 有 GNN/MD 经验，能搞到 GPU | 方向二 | 天花板高，但需相对 NeuralMD 做出 Phys/Dyn/Stab 差异 |
| 强 Agent 工程 + 能读材料论文 | 方向三 | 证据链与开源质量易展示；路线 A 对「LLM+搜索」叙事友好 |
| 有真实科研问题，愿打磨环境与日志 | 开放探索 | 评审看设计质量；负结果可用；差异化最大 |
