## 2. 方向三定位与结构

**定位：** 构建从文献出发、产出**可证伪**科学发现的智能体（材料–性质关联、隐藏知识连接、新材料设计假设等）。

**结构：** **基本任务（必做）** + 进阶路线 **A / B / C 任选其一**（基本任务产出作为路线输入）。  
亦可选实验自动化闭环、世界模型赋能材料等其他新颖路线——**本队选定路线 A**。

## 3. 基本任务：文献调研 Agent（必做 · 方向内 50%）

### 3.1 能力要求

| 能力 | 要求 |
|------|------|
| 文献检索与筛选 | 按队伍研究方向/问题自主检索并筛选 |
| 知识抽取 | 材料成分、结构、性能、模拟方法、合成条件等结构化信息 |
| Research Gap | 未充分探索方向、矛盾结论、缺失知识连接 |
| 调研报告 | 含 Gap 分析、文献交叉引用的结构化报告/综述 |

### 3.2 推荐工具与数据

| 资源 | 用途 | 获取 |
|------|------|------|
| Sciverse | 语义检索与全文定位；鼓励 **MCP/Skill**（调用记录=可审计证据链） | sciverse.opendatalab.com / sciverse.space |
| MinerU | PDF → 结构化内容 | mineru.net |
| Sci-Base | 2500 万+ 论文等 AI-Ready 语料 | HF：`opendatalab/Sci-Base` |
| 其他公开库 | MP / OQMD / NOMAD / AFLOW 等 | 提交物注明来源与访问方式 |

### 3.3 评估与提交格式（基本任务）

- 考察：文献覆盖针对性、知识抽取结构化、**Gap 质量**、证据链与引用完整性。  
- **每条主张与 Gap 须可溯源至具体文献，并标明所用数据库。**  
- 报告须 **PDF（编译产物）+ LaTeX 源码**（`.tex`、`.bib` 及编译所需文件）；正文引用与参考文献一一对应。  
- 组委会可抽查引用真实性；**虚假引用按违规处理**。  
- 提交物：调研报告（Gap 清单 + 交叉引用 + 证据链）+ **系统说明**。

## 4. 进阶路线 A：构效关系发现（本队选定 · 方向内 50%）

**目标：** 基于调研 Gap 与知识库，结合开源材料库，发掘新颖且可信的 **Structure–Property Relationship**，并给出可信科学解释。

| 要求 | 口径 |
|------|------|
| 搜索方法 | 须用搜索/优化算法（GA、MCTS、贝叶斯优化、符号回归等） |
| 与 LLM 融合 | **深度融合**（种子假说、中间合理性评估、剪枝/聚焦等），非仅用 LLM 生成搜索代码 |
| 可信性与新颖性 | 文献证据链；区分「新知」与「已知」；鼓励 MP / OQMD / NOMAD 交叉验证 |
| 可解释性 | 体现细分领域理解（如热电等）；附清晰科学解释，禁止无实质黑箱文本 |
| 加分 | 材料数据库验证结果 |

**进阶提交物（A）：** 构效关系清单 + 证据链 + **解释文档**。

**最终：** 完整技术报告 + 可复现代码/容器。

### 进阶评分拆分（落在方向内进阶 50% 内）

| 分项 | 权重 |
|------|------|
| 方法创新性 | 30% |
| 可信性与验证充分性 | 30% |
| 科学意义 | 20% |
| 工程完备与可复现性 | 20% |

路线 A 侧重：**构效关系的新颖性与证据支撑**（细则以官方评测说明为准）。
