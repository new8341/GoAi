## 01 赛道概览

### 1.1 基本信息

| 项 | 内容 |

## 04 赛题信息（摘要）

两类题目**独立评审、独立排名**。

### 题目类型一：算法赛题

在给定数据集与评测框架下完成可运行、可复现方案。方向（报名选定其一）：

1. **虚拟细胞**（虚拟酵母扰动响应预测）

3. **材料科学文献驱动的科学发现智能体**

**统一评分、单一冠军**：不按方向分设总排名；方向内量化成绩经跨方向校准后进入总榜，具体折算以官方评测说明为准。

自定义真实未解问题 → 探索环境 → 发现信号；负结果被明确允许。

## A02 方向一：虚拟细胞（**已修订**）

### 任务

酿酒酵母扰动蛋白质组预测：学习跨菌株/化学扰动/培养基/温度/时间/测量上下文的响应，预测完整 **log2** 蛋白质组向量；考察未见化合物、未见菌株及其组合的外推。

### 数据（邮件发放非公开包）

提供 **四个文件**：metadata 与 proteome 各分 train_val / test。  

| 集合 | 样本量 | 蛋白维 |
|------|--------|--------|
| train_val | 各 **8,958** | **5,243** |
| test | 各 **4,454** | **5,243** |

- 覆盖 **6** 菌株、**56** 化合物；**2** 培养基、**2** 温度、**6** 时间点（非完全交叉）。  
- 质控：`pert_id = 48`，不计入 56 化合物，不参与化学扰动预测，可用于批次效应评估。  
- **划分**：由 `split_final` **冻结**。可在 train 内部交叉验证，**不得**改官方 train/val 边界。  
- **「未见」**：实体不在训练划分中，与能否看到真值无关。  
- **训练约束**：仅可用 train 划分蛋白质组标签训练；val/test **不得**参与训练，也不得用于估计任何统计量（含保留蛋白列表与归一化参数）。

### 测试集与最终评审

- 测试集蛋白质组真值**随数据包发布**，供自评，**不作最终排名依据**。  
- 组委会另备**独立内部评测集**用于最终评审，不随赛题发放。  
- 晋级队伍须通过**代码复现核验**；不通过不计成绩。

### 榜单（**规则变化**）

原「封闭数据榜 / 开放知识榜」**合并为统一开放榜**，统一评测、统一排名。  
外部公开资源自赛题发布起即允许，可用于实体特征构建（基因组、化合物结构、通路注释等），**须披露来源与版本**。

### 评测场景

| 场景 | 划分 | 考察 |
|------|------|------|
| S1 | 已见菌株 + 未见化合物 | 新扰动外推 |
| S2 | 未见菌株 + 已见化合物 | 新遗传背景 |
| S3 | 未见菌株 + 未见化合物 | 双重未知 |
| **test_time** | 每条件 6 时间点中随机留出 | **时间插值（非外推）** |

评分模块「双重未知 / **时间插值**」（原「时间外推」已更名）。模块权重与计算方法仍以官方评测说明为准；口径包括绝对保真度、匹配对照 FC、上下文/药物均值残差、双重未知与时间插值、高效应蛋白/DEP、以及复现合规门槛。

### 提交格式补充

- 仅接受 **log2** 尺度；不接受 raw intensity、z-score/标准化空间。  
- 蛋白列须与官方 **feature contract** 完全一致；不得改样本 ID。

### 隐藏机理评估

可用于赛后分析与**特别奖提名**，不作主榜排名依据。

## A03 方向二：小分子–蛋白质结合轨迹（**已修订**）

### 任务

学习结合动力学，预测未见复合物轨迹。以**单轨迹重建为主**；**多轨迹子任务不再设置**。

### 数据

- 以 MISATO **原始 MD 划分**为准（剔除 NeuralMD 仓库 `peptides.txt` 多肽条目）：训练 **13,066**，验证与测试各 **1,357**；测试为全新复合物。  
- 训练集内自建验证集时，**建议**按蛋白序列一致性与配体骨架相似度去泄漏（由强制改为建议）。  
- 评测将使用 MISATO 公开数据 + **组委会独立评测数据**（不随赛题发放，用于成绩核验）。

### 评测档次（推理任务，非训练划分）

| 档次 | 设定 | 角色 |
|------|------|------|
| T1 | 给定前 **10** 帧，预测后 **10** 帧 | 主评测 |
| T2 | 给定前 **80** 帧，预测后 **20** 帧 | 主评测 |
| T3 | 给定前 **20** 帧，预测后 **80** 帧 | 主评测 |
| **T4** | 给定初始若干帧，预测长程轨迹 | **可选加分** |

### 评分

- 维度仍为 Geo / Phys / Dyn / Stab。  
- **各维度计算方式、权重与最终合成方式随评测说明发布**（原固定公式暂不作为本修订版硬编码）。  
- **统一 semi-flexible**：蛋白不动，只预测配体原子坐标序列。  
- NeuralMD 为**相关可参考工作**；归一化/折算随评测说明。保留静态/线性平凡基线。  
- Geo/Phys/Dyn/Stab 精确定义、细则与提交格式说明：**随复赛通知发布**；初赛不涉及。

## A04 方向三：材料科学文献驱动的科学发现智能体（**0816 对齐**）

### 赛题定位

面向材料科学，考察能否构建**从文献出发、产出可验证科学发现**的智能体：材料–性质关联、隐藏知识连接、新材料设计假设等，须具**可证伪性**。

### 结构

**基本任务（必做）** + 进阶路线 **A / B / C 任选其一**（基本任务产出作为路线输入）。亦可选实验自动化闭环、世界模型赋能材料等其他新颖路线。

### 基本任务：文献调研 Agent

- 文献检索与筛选 → 知识抽取（成分/结构/性能/模拟/合成等）→ Research Gap → 结构化调研报告（交叉引用 + 证据链）  
- **推荐工具：** Sciverse（语义检索与全文定位）、MinerU（PDF→结构化）；**鼓励 Sciverse API 的 MCP/Skill 接入**（调用记录构成可审计证据链）  
- **开放语料：** Sci-Base 可经 Hugging Face `opendatalab/Sci-Base` 获取（以官网赛道页为准）  
- **评估：** 文献覆盖针对性、知识抽取结构化、Gap 质量、证据链与引用完整性；**每条主张/Gap 须可溯源至具体文献，并标明所用数据库**  
- **提交格式：** **PDF（编译产物）+ LaTeX 源码**（`.tex`、`.bib` 及编译所需文件）；正文引用与参考文献一一对应；虚假引用按违规处理  

### 路线 A：构效关系发现

- 基于 Gap 与知识库，结合开源材料库发掘 SPR，并给可信科学解释  
- 须用搜索/优化（GA、MCTS、贝叶斯优化、符号回归等）且与 **LLM 深度融合**（种子假说、中间合理性评估、剪枝/聚焦），非仅生成搜索代码  
- 区分「新知」与「已知」；鼓励 MP / OQMD / NOMAD 等交叉验证  
- 强调细分领域理解与可解释性；**加分：材料数据库验证结果**  

### 路线 B：模拟方法创新

- DFT 加速、MC/MD 新架构、生成式模型增强；**含 Ising 等经典 MC 与 QMC 的创新/加速**  
- **须相对** Metropolis / Swendsen–Wang / Wolff 等**量化**效率或临界慢化改进  
- Benchmark（MD17、QM9、MP 轨迹等）或细分领域优异；加分：实验或真实体系实用价值  

### 路线 C：合成路线与工艺设计

- 合成路线生成（前驱体/条件/步骤 + 文献依据）与工艺优化  
- **热力学可行性检验**（形成能/热力学或 DFT）；实验验证可选  
- 须展示推理过程；鼓励逆向合成 + LLM；加分：实验验证或可量化工艺优化  

### 数据库范围

不限于 Sci-Base / Sciverse / MinerU / MP / OQMD / NOMAD；可选用任何公开可获取科学数据库（如 AFLOW），提交物注明来源与访问方式。

### 材料方向评估

方向内：**基本任务 50% + 进阶路线 50%**。

进阶路线拆为：

| 分项 | 权重 |
|------|------|
| 方法创新性 | 30% |
