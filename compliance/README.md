# 合规与披露 · compliance/

复赛起必填。对照官方「开源与合规要求」维护本目录。

## 建议文件

| 文件 | 用途 |
|------|------|
| `DEPENDENCIES.md` | 开源依赖、许可证、关键版本 |
| `API_AND_CLOSED_MODELS.md` | 商业 API / 闭源模型：调用环节、费用假设、权限、可替代性、对复现的影响 |
| `DATA_SOURCES.md` | 数据来源、授权状态、使用边界（尤其官方非公开数据） |
| `PRIOR_WORK.md` | 基于已有项目时：来源、团队贡献、新增创新点、协议兼容性 |
| `OPEN_SOURCE_PLAN.md` | 初赛可用：开源计划与边界说明 |

提交前将本目录关键文件一并纳入 `submissions/semi_final/` 与 `submissions/final/`。
