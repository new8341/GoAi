## 1. 表单建议填写

| 字段 | 建议内容 |
|------|----------|
| **作品名称** * | `材料科学文献驱动的科学发现智能体（Materials Agent）` |
| **选题** * | 选 **算法类**，并选到 **方向三 / 材料文献**（页面若写作「规则类第一: 算法类」等，以能对应方向三的选项为准） |
| **代码仓库** | 有公开 GitHub/Gitee 再填；暂无可留空，代码已在 zip 的 `code/` |
| **Demo 链接** | 本地演示可写：`（本地）python scripts/serve_viewer.py → http://127.0.0.1:8765/?run=production_sciverse`；无公网 Demo 可留空或写「见附件 README」 |
| **作品附件 (.zip)** * | 上传本目录最新 `GOAI_赛道三_材料文献Agent_作品提交_*.zip` |
| **所在地/单位** * | 按队员实际情况填 |
| **个人职称/身份** * | 如：学生 / 工程师 / 教师 |
| **成员 2** | 有第二人则填；单人队可按页面是否必填处理 |
| **收件人姓名/电话/地址** * | 礼品邮寄用，填真实可收件信息 |
| **短袖尺码** * | 按尺码表选择 |

## 3. 提交步骤

1. 登录 → 作品提交 → **确认赛道**  
2. 填作品名称、选题、单位身份、邮寄与尺码  
3. 点击上传区，选择 `GOAI_赛道三_材料文献Agent_作品提交_*.zip`  
4. 点 **提交作品**  
5. 在「本赛段提交记录」确认出现新记录且状态为审核中/已提交，并截图

---

## 4. 注意

- 多次提交以**最后成功版本**为准（页面已说明）。  
- 初赛规划额度约 **1/3 次**（截图显示初赛已用 1 次）——误赛道那次可能已占次数，正确赛道下仍应提交正本。  
- 勿把含 `.env` / 付费 PDF 的目录打进 zip。
