# 开源计划与边界（初赛提交版）

> 同步自仓库 `compliance/OPEN_SOURCE_PLAN.md`，并按 2026-08 工程现状补强。

---

## 1. 计划开源范围

- **代码**：`tracks/algorithm/materials_agent/` 全流水线（检索 / 全文 / 抽取 / Gap / 报告 / Route A / 双 UI / 门禁脚本）  
- **配置**：`configs/*.yaml`、ontology、专家核对标准 JSON  
- **文档**：README、使用说明、DEPENDENCIES、初赛/答辩材料、复现剧本  
- **模型权重**：无自研权重；外部闭源 API 仅披露调用方式，不封装密钥  

拟许可证：**Apache-2.0**（需与上游依赖最终核对）。

---

## 2. 暂不开放或受限部分

| 内容 | 原因 |
|------|------|
| `.env` 与真实 API Token | 安全 |
| 付费墙 / 授权不允许再分发的原始 PDF | 版权与赛题合规 |
| Qdrant 持久化卷、MinerU 大模型缓存 | 体积与可复现无关噪音 |
| 人工 Gap 金标准（若后续有协议限制） | 协议 |

---

## 3. 数据与工具来源（摘要）

| 来源 | 用途 | 分发 |
|------|------|------|
| OpenAlex | 文献元数据检索 | 按 OpenAlex 条款 |
| Unpaywall | 合法 OA PDF 定位 | 按服务条款 |
| Sciverse | 赛题推荐检索 | Token 自备，不入库 |
| GROBID `0.8.0` | PDF→TEI | 开源镜像（docker-compose 钉版本） |
| Qdrant `v1.13.2` | 证据向量索引 | 开源镜像（钉版本） |
| Materials Project | Route A 外验 | API Key 自备 |
| 可选 LLM API | 抽取/Gap/Route A | 可关；启发式可降级；版本写入 `external_versions.json` |

访问方式与 profile 对照见仓库 `DEPENDENCIES.md`「External resources」表。初赛须随源码披露种子/参数（YAML）与外部资源来源版本。

## 4. 复现入口（最小）

```bash
cd tracks/algorithm/materials_agent
pip install -r requirements.txt
copy .env.example .env
python scripts/run_survey.py survey -c configs/demo_local.yaml
python scripts/serve_viewer.py
```

生产证据链另需 GROBID（及可选 Qdrant）与 Sciverse Token，见 `DEPENDENCIES.md` 与 `scripts/reproduce_production_sciverse.ps1`。
