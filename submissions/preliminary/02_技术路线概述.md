# 技术路线概述  
## 材料文献 Agent · 基本任务 + 路线 A

> 初赛提交配套 · 2026-08-12  
> 实现目录：`tracks/algorithm/materials_agent/`

---

## 1. 总体架构

```text
configs/*.yaml
  → LiteratureSurveyAgent (pipeline)
       rewrite → retrieve → fulltext/parse → chunk/index
       → extract → known → gaps(+evidence) → review
       → metrics → report → consistency → save
  → outputs/<run>/
  → 门禁：verify_production | science_review_gate | objective_review
  → UI：user（黑盒）/ viewer（白盒）
  → Route A（可选）：SEED→SCORE→PRUNE→MUTATE→MP 外验
```

模块边界：`materials_agent/agents/` 业务逻辑；`tools/` I/O 与解析；`scripts/` 门禁与运维；`user/`+`viewer/` 双验收界面。

---

## 2. 基本任务流水线（逐步）

| 步骤 | 模块 | 关键设计 |
|------|------|----------|
| Query | `query_rewriter` | 规则/LLM 多意图；生产 Sciverse 金标可关 rewrite |
| 检索 | `retrievers` | OpenAlex / Sciverse / Semantic Scholar；**生产禁止静默假后端**（`allow_backend_fallback: false`） |
| 全文 | `oa_download` + `fulltext` | Unpaywall 合法 OA；GROBID 主解析（Windows 避开 MinerU 挂死） |
| 标题卫生 | `paper_titles` | TEI/全文回填，禁止 `SV-paper` stem 进报告 |
| 索引 | chunk + file/Qdrant | Qdrant 失败显式降级 file |
| 抽取 | `extractor` | 材料/性质/方法/局限 + 证据消毒 |
| Known | `known_map` | 抑制「语料内常识当首次发现」 |
| Gap | `gap_finder` + `evidence_selector` | 强制全文证据、provenance、boilerplate 过滤 |
| 评审 | `gap_reviewer` | keep/revise/reject + 主题材料门禁 |
| 监控 | `topic_focus` | topic_hit / gap 对齐 / boilerplate / provenance |
| 报告 | `reporter` + `consistency` + **LaTeX export** | 交叉引用 + 一致性；`report.tex`/`references.bib`；每条 Gap 标明 **Database** |

## 3. 路线 A（构效搜索）

| 角色 | 行为 |
|------|------|
| SEED | 模板播种；LLM 可 refine 为可证伪单句假说 |
| SCORE | JSON `{plausibility, mechanism, keep}` |
| PRUNE | 低合理度软剪枝 |
| MUTATE | FOCUS 邻近变异或规则变异 |
| 外验 | Materials Project；失败降分并写 `role_trace` |

入口：`scripts/run_route_a.py -c configs/production_route_a.yaml --bundle-dir outputs/production_sciverse`

**进阶路线评分口径（手册 2026-08）：** 方法创新 30% · 可信与验证 30% · 科学意义 20% · 工程完备与可复现 20%。`route_a_spr_report.md` 末尾有对应叙事模板。

---

## 4. 验收与分层门禁

| 门禁 | 证明什么 | 产物文件 |
|------|----------|----------|
| `verify_production` | OA 解析率、无 local_cache 冒充、quote⊂source、无噪声证据、后端诚实 | **仅** `production_verification.json` |
| `science_review_gate` | L0 机械科学门禁 + L1 双角色抽样 | `science_review.json` |
| `objective_review_run` | 专家标准自动判决（非领域专家项） | `objective_review.json` + `objective_verify_shadow.json`（**不覆盖**工程验收文件） |

## 6. 依赖与运行（最小）

```bash
cd tracks/algorithm/materials_agent
pip install -r requirements.txt
copy .env.example .env   # 填入自有密钥，勿提交
docker compose up -d grobid qdrant   # 生产解析/索引
python scripts/run_survey.py survey -c configs/demo_local.yaml
python scripts/serve_viewer.py
```

完整依赖与降级策略见工程内 `DEPENDENCIES.md`。
