## 1. 为何这个问题值得做

热电材料中，**晶格热导率 κ_L** 是功率因子之外调节 zT 的关键杠杆。SnSe 因其强各向异性与本征低 κ_L 成为近十年焦点；**空位 / 点缺陷散射**被广泛讨论，但文献对「何种空位浓度与测量语境下 κ_L 响应可复现」仍存在缺口与矛盾表述。将文献调研 Agent 的 Research Gap 转成**可证伪的构效假说**，再经 Materials Project 等公开库打脸，符合「AI 预测 → 可验证」闭环，而非堆砌综述。

## 2. Gap → SPR 的科学链条

1. **基本任务**在 Sciverse OA 全文证据链上识别 Gap（空位浓度系列、测量语境混淆、方法缺口等），每条主张标明数据库并保留 quote⊂source。  
2. **路线 A**以 Gap 对齐度为目标之一，搜索结构–性质假说（SEED→SCORE→PRUNE→MUTATE）。  
3. **已知 vs candidate_new** 标签抑制把语料内常识写成「首次发现」。  
4. **MP 外验**要求 motif 可查询化学式，用稳定性 / e_above_hull 软约束，避免「只会写句子」。

## 4. 可证伪协议（答辩可用）

对 Top-K `candidate_new` 假说：给出空位浓度或掺杂窗口、预期 κ_L 变化方向、以及「若 MP/实验相反则推翻」的 falsification 句（见 gaps.json / SPR 报告）。湿实验 / 全 DFT 闭环为加分项，复赛以**协议完整 + 公开库交叉**为主。
